# SoundStream

SoundStream es una plataforma de streaming musical desarrollada como proyecto académico en la Universidad Santiago de Cali. Permite a los usuarios descubrir, reproducir y organizar música, mientras ofrece a los artistas herramientas para publicar y gestionar su catálogo.

El sistema está compuesto por un backend en Node.js con Fastify y PostgreSQL, y una aplicación cliente multiplataforma desarrollada en Flutter para web y Android.
